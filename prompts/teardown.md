# Teardown-Prompt

Wird von `/teardown` verwendet. Platzhalter in eckigen Klammern kommen aus `brand/<marke>/`.

```
Der Operator hat eine Wettbewerber-Ad reingegeben (Link, Screenshot oder
Transkript). Führ den 4-teiligen Teardown aus. Zitier die Quelle
(Ad-Library-ID, URL oder Dateiname) in der ersten Zeile.

TEIL 1 · HOOK
- Hook-Zeile wörtlich (erste 3 bis 4 Sekunden)
- Mechanik aus der 10er-Liste: contrarian / curiosity / number /
  named-enemy / demo / confession / reframe / stakes / reversal / absurd
- Warum dieser Hook den Scroll von [ICP aus icp_core.md] stoppt, ein Satz

TEIL 2 · MECHANIK
- Die Überzeugungsmechanik unter dem Hook: authority-transfer /
  social-proof-stacking / status / risk-reversal / scarcity /
  novelty-escalation / identity / anti-status
- Wie sie sich durch die Shot-Folge aufbaut
- Welche andere Mechanik hier auch funktioniert hätte, aber nicht benutzt wird

TEIL 3 · EMOTIONALER BOGEN
- Beat für Beat: Frustration / Neugier / Wiedererkennen / Hoffnung /
  Überzeugung / Handlung, mit Sekundenangabe
- Der Peak (welcher Beat)
- Das Loch (wo Aufmerksamkeit abreißen kann)

TEIL 4 · BELIEF SHIFT
- Was der Zuschauer bei Sekunde 0 glaubt
- Was er am Ende glaubt
- Der Moment, an dem der Wechsel passiert (Sekunde, Shot)
- Der Beweis oder die Mechanik, die den Wechsel trägt

Gib alle vier Teile als Markdown mit genau diesen Überschriften aus.
Erfinde keine Kennzahlen zur Ad. Wenn Laufzeit oder Reichweite bekannt
sind, nenn die Quelle. Kein Gedankenstrich.
```

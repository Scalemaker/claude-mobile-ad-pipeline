# Beispiel-Lauf

Ein vollständiger Teardown und Rebuild zum Nachlesen, damit du siehst, was die Pipeline liefert, bevor du deinen ersten eigenen Lauf startest.

**Die Quell-Ad ist konstruiert.** Sie fasst ein Muster zusammen, das in der Kategorie Trinkflaschen seit Jahren läuft (Problem mit Plastikgeschmack, Demo, Preisanker), ist aber keine echte Anzeige eines echten Unternehmens. Kennzahlen zur Quell-Ad stehen deshalb keine drin. Die Beispielmarke „demo" mit dem Produkt „Isolierflasche 750" ist ebenfalls fiktiv; ihre Markendateien liegen in `brand-demo/`.

Was fehlt, absichtlich: gerenderte Clips. Die kosten Credits und würden nur zeigen, wie Higgsfield an einem Tag gerendert hat. Deinen ersten Render machst du mit deinem Produkt, und der Preis steht vorher im Chat.

| Datei | Was |
|---|---|
| `source.md` | die Quell-Ad als Transkript plus Frame-Beschreibung |
| `teardown.md` | die vier Teile |
| `rebuild.md` | Hook, 6-Shot-Storyboard, Voiceover, Locks, Vorbilder |
| `prompts.md` | die fünf Format-Prompts, wie `/render` sie an Higgsfield schicken würde |
| `brand-demo/` | die Markendateien, gegen die der Rebuild geprüft wurde |
